# LOW ACRYLONITRILE NBR PATENT REPORT: EVIDENCE FROM US11347156B2

## 1. ABSTRACT
This report synthesizes the patent evidence available in the required manifest for low acrylonitrile NBR, with the manifest containing a single primary patent: US11347156B2. The patent is not directed to NBR synthesis or monomer-feed control; instead, it concerns an electro-conductive member for electrophotography that uses a matrix-domain rubber architecture. Within that architecture, acrylonitrile-butadiene rubber (NBR) appears as one of the candidate diene-based rubbers for either the matrix or the domains, paired with styrene-butadiene rubber (SBR) in the complementary phase. The extracted evidence includes explicit nitrile-content values for several commercial NBR grades used as reference materials in the examples, ranging from 15% to 41.5%, which provides context for low- versus higher-acrylonitrile grades, but these values are not disclosed as properties of the claimed target material itself. The patent’s core technical contribution is phase-separated rubber design: a first rubber composition forms the matrix, a second rubber composition forms conductive domains, and the two rubbers are selected to differ in monomer units and to have controlled solubility-parameter separation and viscoelastic matching. The examples emphasize formulation-driven performance rather than polymerization chemistry, using NBR, SBR, IR, BR, EPDM, CR, and hydrin as raw rubbers, along with carbon black, sulfur, and vulcanization accelerators. Water is not part of the polymerization process because no polymerization is disclosed; the evidence instead shows dry compounding, molding, and evaluation of electro-conductive members. Overall, the patent is only indirectly relevant to low acrylonitrile NBR because it documents NBR grades and their use in a functional rubber composition, but it does not disclose NBR preparation, acrylonitrile feed control, or synthesis conditions for low-acrylonitrile NBR.

## 4. CONCLUSION
The single primary patent in the manifest, US11347156B2, is not a synthesis patent for low-acrylonitrile NBR; it is a formulation and device patent that uses NBR as one of several rubber materials in a matrix-domain electro-conductive member. The evidence provides useful compositional context, including explicit nitrile contents for several commercial NBR grades, but it does not disclose preparation conditions, monomer feed ratios, or polymerization routes for low-acrylonitrile NBR.
